This GitHub project is a sandbox environment for learning and experimenting with new concepts, techniques, and technologies, with a focus on applying them to practical, real-world scenarios 
using java and spring boot.
Topics - 
1. Parallel processing of rules being injected via the database.
2. Ordered processing of events in a multi producer - consumer Kafka cluster.
3. Authorization server using OAuth2.
4. Component testing framework.
5. Creating a service Map for microservices.
6. Observability in microservices(tracing, logs and spans).
7. Handling ever increaing mongo document size (Data movement to an optimised schema).
8. GraphQL basics.
9. API gateway baisics using kong(Authorization, caching, rate limiting).
